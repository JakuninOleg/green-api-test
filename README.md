# Чат GREEN-API

Минимальный текстовый чат на React + TypeScript + Vite с Telegram через GREEN-API. Интерфейс: список чатов, лента входящих и исходящих сообщений, поле отправки.

Live версия - [https://green-api-test-ten-mu.vercel.app/](https://green-api-test-ten-mu.vercel.app/)

Оформление основано на тёмной теме [MAX](https://web.max.ru/) и официальных примерах [для компьютера](https://download.max.ru/#desktop) и [телефона](https://max.ru/). Цвета и фон взяты из веб-версии MAX; Roboto хранится локально с [лицензией OFL](public/fonts/OFL.txt). На телефоне список чатов и переписка открываются отдельными экранами.

## Запуск

Требуется Node.js 24 LTS.

Создайте `.env.local` по образцу `.env.example`. Укажите в `VITE_GREEN_API_URL` значение `apiUrl` из [кабинета GREEN-API](https://console.green-api.com/).

```bash
npm ci
npm run dev
```

Откройте http://localhost:5173. Введите `idInstance` и `apiTokenInstance` авторизованного инстанса Telegram.

Реквизиты, чаты и сообщения хранятся только в памяти вкладки. После перезагрузки или отключения их нужно ввести снова. Запросы идут напрямую из браузера в GREEN-API.

## Проверка чата

1. В кабинете GREEN-API авторизуйте инстанс и включите входящие уведомления (`incomingWebhook: "yes"`). Для [получения через HTTP API](https://green-api.com/en/telegram/docs/api/receiving/technology-http-api/) поле `webhookUrl` должно быть пустым. Не запускайте другой потребитель очереди для этого инстанса.
2. Подключитесь с `idInstance` и `apiTokenInstance`.
3. Нажмите «+», введите телефон собеседника с кодом страны, например `+7 (999) 123-45-67`, и нажмите «Начать». Приложение вызывает [CheckAccount](https://green-api.com/telegram/docs/api/service/CheckAccount/) и открывает чат по Telegram `chatId`. Если API определил аккаунт, ответы со скрытым номером (`senderPhoneNumber: 0`) попадают в тот же чат. Настройки приватности Telegram могут запретить поиск самого аккаунта по номеру.
4. Отправьте текст кнопкой со стрелкой или Enter. Shift+Enter вставляет новую строку. После подтверждения SendMessage появится исходящий пузырь. При ошибке текст остаётся в поле для повторной отправки.
5. Ответьте с аккаунта собеседника. Входящий текст появится автоматически: ReceiveNotification с `receiveTimeout=5`, затем обработка и DeleteNotification по `receiptId`.
6. Нажмите «Выйти»: запросы отменятся, приложение вернётся к форме подключения.

Отображаются только `textMessage` и текст `extendedTextMessage`. Остальные уведомления удаляются из очереди без отображения. Пустая очередь — нормальный ответ; ошибки приёма показываются в интерфейсе, повтор выполняется через 2 секунды. При повторной доставке входящие сообщения не дублируются по `idMessage`.

## Публикация

Команда `npm run build` создаёт статические файлы в `dist`. Их можно разместить на статическом хостинге. Адрес API задаётся перед сборкой.

Для локального просмотра сборки:

```bash
npm run preview
```
